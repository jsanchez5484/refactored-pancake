## Деплoy

1. New repo → `kimi-k3` (public) на аккаунте `vict-garcia-948`
2. Upload из `kimi-k3-landing/`:
   ```
   index.html
   css/
   js/
   assets/
   .nojekyll
   ```
3. Settings → Pages → main → / (root)

Лендинг содержит интерактивный **Kimi K3 Client** mockup:
- Random prompt через 1.8 сек после загрузки
- Кнопка 🎲 Random — случайный вопрос + полный ответ с typing
- 6 заготовленных full-response сценариев (код, SQL, архитектура и т.д.)
- Картинки с официальных источников: kimi.com, HuggingFace, statics.moonshot.cn
